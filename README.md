# E-Commerce Website for Gadgets

A multi-page, responsive e-commerce website for gadgets built with HTML, CSS, and Bootstrap. The site includes a homepage, product listing, multiple product detail pages, cart, login, and admin screens.

## Highlights
- Modern responsive layout using Bootstrap 5
- Product catalog and dedicated product detail pages
- Cart, login, and admin pages
- Consistent header/footer across pages
- Simple static setup with no build step

## Pages
- `index.html` - Homepage
- `product.html` - Product catalog/listing
- `product details.html` - Primary product detail page
- `product-*.html` - Individual product detail pages
- `cart.html` - Cart page
- `login.html` - Login page
- `admin.html` - Admin page

## Tech Stack
- HTML5
- CSS3
- Bootstrap 5

## Project Structure
- `index.html`, `product.html`, `product details.html`, `product-*.html` - HTML pages
- `style.css` - Shared styles
- `8743024fa6c2a7a62f8a2d85ca0d4b46.jpg` - Hero/product image asset

## Run Locally
1. Open `index.html` in your browser.
2. Optional: run a simple local server to avoid browser file restrictions.
   - Example (PowerShell): `python -m http.server`
   - Then visit `http://localhost:8000`
